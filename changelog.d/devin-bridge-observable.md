### Internal
- The Devin approval bridge (`devin-clean-approves.yml`) is now a poller that runs only from the default branch, every ten minutes and on dispatch, instead of on `pull_request_review` events: the event form executed the PR's own copy of the workflow with a write token, so a same-repository author could have edited the gate, and its first version silently skipped Devin's events anyway. Membership is no longer inferred from `author_association`; a same-repository branch whose author is not in the repository's outside-collaborators list is an organization member. Devin's "N security issues" headline counts as an issues verdict, and every PR's decision is logged (#2295).
