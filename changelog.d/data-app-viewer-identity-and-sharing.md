### Added
- **A hosted data app now knows who's looking.** The ingress proxy adds a signed `X-Agnes-Viewer` header (a compact, per-app HS256 JWT — `sub`/`email`/`name`/`groups`/`aud`/`via`, 5-minute TTL) to every proxied request and WS handshake, so an app can personalize a page or gate a section by viewer identity without any RBAC implication. The baked `nodejs-dashboard` scaffold's `server/agnesViewer.ts` (`getViewer`/`requireViewer`/`viewerTokenFrom`) is the sanctioned way to read it; a Python snippet for Flask/Streamlit apps is in the `agnes-data-apps-extras` skill's `references/agnes-query.md`.
- **Opt-in viewer data identity.** `PATCH /api/data-apps/{slug}` `{"data_identity": "viewer"}` (owner or Admin, Postgres-backed instances only — `501 requires_postgres_backend` on DuckDB) switches an app's data access from the owner alone to **owner ∩ viewer**, evaluated live on every request, and additionally adds a short-lived `X-Agnes-Viewer-Token` the app can forward as a bearer token to the Agnes data API. Switching modes redeploys the app. New CLI `agnes app set-identity <slug> owner|viewer` and MCP `data_app_set_data_identity(slug, data_identity)`.
- **Sharing a hosted app from the CLI, MCP, and its detail page.** `agnes app share <slug>` (show, or `--group NAME... [--everyone] [--private]` to change), MCP `data_app_share_get`/`data_app_share`, and a Share control plus a Data identity toggle on `/apps/detail/<slug>` — all thin wrappers over the existing owner-scoped `GET/PUT /api/sharing/data_app/<slug>`. The `agnes-data-apps-extras` skill now prompts the user for who should see a just-published app rather than sharing on its own initiative.
- The deploy-time exposure scan (`DA005`, `src/data_apps/deploy_check.py`) now also flags `AGNES_VIEWER_SECRET` and the `X-Agnes-Viewer-Token` header value echoed back on a response line, alongside the existing `AGNES_TOKEN` check.

### Changed
- `PATCH /api/data-apps/{slug}`'s body fields are now all optional; an empty `{}` body returns `400 nothing_to_update` instead of silently succeeding.
