### Internal
- A clean Devin verdict now supplies the approving review that lets an organization member's pull request (or the daily release-cut PR) enter `main`'s merge queue, and is dismissed again when a later Devin review lists issues (`devin-clean-approves.yml`). The queue evaluates the one-approval rule as itself, so ruleset bypass no longer let a member queue an unreviewed PR; outside collaborators' PRs still need a human approval (#2295).
