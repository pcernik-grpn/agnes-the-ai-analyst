{# The per-section tab strip — tier two of the admin navigation. The sidebar names PLACES (Overview · People · Data · Access · Library · Instance · Activity); this names the lenses INSIDE the place you are in ("Sources · Tables · Packages · Semantic"). Sub-navigation visible only where it applies, instead of ~28 rows in a column where finding Tables meant knowing which of seven headings owns it. Data comes from `app/web/admin_nav.py` — the SAME inventory the sidebar reads, via `resolve_section_tabs(path)` (the Jinja global `admin_nav_tabs`), which also resolves which tab is active. One source of truth, so a tab and a sidebar row can never disagree about what exists, and the coverage guard in `tests/test_web_admin_nav.py` sees both tiers. EVERY TAB IS A REAL LINK, not a pane switch. Each lens keeps its own URL, so deep links, bookmarks, the back button and the reverse guard behave exactly as they did when these were sidebar rows — no page in the admin area mixes the two models. A lens that must not lose state on a switch keeps it across the navigation instead (Access's editor restores its selected group from sessionStorage), which costs one small handler and buys a URL you can send to someone. The QUERY goes in as well as the path, for the one tab whose page it shares with a sibling: `/admin/access?lens=simulate`. `resolve_section_tabs` needs both to tell those two apart — see its docstring. Renders NOTHING when the current section has no tabs — a legacy disclosure group, a tabless destination, or an off-nav page (`ADMIN_NAV_OFFNAV`). A one-tab strip is chrome that says nothing, so the empty case is silence rather than a decorative single tab. Include at the TOP of a page's own content block, under the hero and any toolbar actions — that is where sub-navigation reads as belonging to the page rather than to the window. Uses the shared `ds.tabs` component (`.tab-strip`, the same strip /library and /chats use), never a local copy; `ds` is auto-imported by base_ds.html, so no import is needed here. #} {% set _tabs = admin_nav_tabs(request.url.path, request.url.query) %} {% if _tabs %} {% set _flow = _tabs | selectattr('chain') | list %}
